# 🌐 Simple Website Template

This is a **basic copy website template** created using only **HTML** and **CSS**.  
It is a simple project for beginners who are just starting their journey in **web development**.

---

## 📖 Features
- Simple and clean layout  
- Fully responsive (works on mobile & desktop)  
- Created only with **HTML & CSS** (No frameworks, no JavaScript)  
- Easy to understand for beginners  

---

## 🛠️ Technologies Used
- **HTML5**
- **CSS3**
